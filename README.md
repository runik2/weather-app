# Погода — минимальное веб-приложение

Одна страница, без сборки и зависимостей. Открывается двойным кликом по `index.html`.

## Что умеет

- Показывает текущую погоду для любого города (поиск по названию, на русском)
- Ближайшие 8 часов и прогноз на 5 дней
- Меняет фон под погоду: ясно, облачно, дождь, снег, ночь
- Запоминает последний город в `localStorage`

## Данные

[Open-Meteo](https://open-meteo.com) — бесплатно, без ключа и без регистрации.
Геокодинг: `geocoding-api.open-meteo.com`. Прогноз: `api.open-meteo.com/v1/forecast`.

## Запуск

Просто открыть `index.html` в браузере. Либо поднять локальный сервер, если
нужен доступ с телефона в той же сети:

```bash
python -m http.server 8080
```

## Проверка

`python verify.py` — делает те же запросы, что и приложение, и печатает результат.
Полезно, чтобы убедиться, что API жив, не открывая браузер.

## Структура

```
index.html   вся разметка, стили и логика
verify.py    проверка API из консоли
```

Ключей, аккаунтов и секретов нет.
